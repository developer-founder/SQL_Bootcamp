# 🧠 RDBMS is not just a tables

Проект посвящён изучению функций, триггеров и механизмов аудита в PostgreSQL.

В рамках выполнения заданий рассматриваются создание SQL и PL/pgSQL функций, реализация триггеров для контроля изменений данных, построение системы аудита, работа с представлениями и параметризованными функциями, а также разработка алгоритмов на стороне базы данных.

Основная цель проекта — сформировать понимание того, что современная реляционная СУБД является не только хранилищем таблиц, но и полноценной платформой для реализации бизнес-логики, автоматизации обработки данных и обеспечения их целостности.

## 🧪 Задание 00

Реализовать механизм аудита операций INSERT для таблицы `person`.

Необходимо:

- создать таблицу `person_audit`
- добавить служебные поля аудита
- создать триггерную функцию `fnc_trg_person_insert_audit`
- создать триггер `trg_person_insert_audit`

После создания выполнить вставку новой записи:

```sql
INSERT INTO person(id, name, age, gender, address)
VALUES (10, 'Damir', 22, 'male', 'Irkutsk');
```

## 🧪 Задание 03

Объединить все механизмы аудита в единый универсальный триггер.

Необходимо:

- удалить старые триггеры
- удалить старые триггерные функции

  - INSERT
  - UPDATE
  - DELETE

```sql

UPDATE person SET name = 'Damir' WHERE id = 10;
```

## 🧪 Задание 06

Создать функцию на PL/pgSQL для поиска подходящих пиццерий.

Функция `fnc_person_visits_and_eats_on_date` должна:

- принимать имя пользователя
- принимать максимальную стоимость пиццы
- принимать дату посещения
- возвращать список подходящих пиццерий

Значения по умолчанию:

- пользователь — `Dmitriy`
- цена — `500`
- дата — `2022-01-08`

Примеры вызова:

```sql
SELECT *
FROM fnc_person_visits_and_eats_on_date(
    pprice := 800
);

SELECT *
FROM fnc_person_visits_and_eats_on_date(
    pperson := 'Anna',
    pprice := 1300,
    pdate := '2022-01-01'
);
```

## 🧪 Задание 07

Реализовать функцию поиска минимального значения массива.

Необходимо создать функцию:

```sql
func_minimum()
```

Функция принимает массив чисел и возвращает минимальное значение.

Пример вызова:

```sql
SELECT func_minimum(
    VARIADIC arr => ARRAY[10.0, -1.0, 5.0, 4.4]
);
```

## 🧪 Задание 08

Реализовать генератор чисел Фибоначчи на стороне базы данных.

Необходимо создать функцию:

```sql
fnc_fibonacci()
```

Требования:

- параметр `pstop` типа integer
- значение по умолчанию — `10`
- вернуть все числа Фибоначчи, меньшие `pstop`

Примеры вызова:

```sql
SELECT *
FROM fnc_fibonacci(100);

SELECT *
FROM fnc_fibonacci();
```
