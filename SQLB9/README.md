# 🧠 Aggregated Data and SQL Analytics

Проект посвящён изучению агрегатных функций и аналитической обработки данных в PostgreSQL.

В рамках выполнения заданий рассматриваются группировка данных, вычисление статистических показателей, фильтрация агрегированных результатов, объединение данных из нескольких таблиц и построение аналитических отчётов на основе бизнес-метрик.

Основная цель проекта — сформировать понимание того, как преобразовывать сырые данные в полезную аналитическую информацию для принятия обоснованных бизнес-решений.

## ⚙️ Рекомендации к выполнению проекта

* Используй актуальную версию PostgreSQL
* Пиши SQL-запросы в удобной среде разработки (DataGrip, DBeaver, pgAdmin и др.)
* В репозитории должны оставаться только файлы, указанные в заданиях
* Настрой `.gitignore`, чтобы исключить лишние файлы
* Перед началом работы разверни предоставленную модель базы данных
* Внимательно соблюдай ограничения каждого задания
* Используй агрегатные функции и группировку данных осознанно
* Проверяй не только корректность результата, но и точность вычисляемых метрик

## 🧩 Структура базы данных

Проект основан на реляционной модели, включающей:

* **person** — пользователи системы
* **pizzeria** — список пиццерий
* **menu** — меню и цены
* **person_visits** — посещения пиццерий
* **person_order** — заказы пользователей

Связи между таблицами заданы явно через первичные и внешние ключи.

## 🧪 Задание 00

Подсчитать количество посещений пиццерий для каждого пользователя.

Получить:

* идентификатор пользователя
* количество посещений

Отсортировать результат:

1. по количеству посещений по убыванию
2. по идентификатору пользователя по возрастанию

## 🧪 Задание 01

Модифицировать предыдущее решение.

Получить:

* имя пользователя
* количество посещений

Дополнительно:

* вывести только топ-4 пользователей по количеству посещений
* отсортировать результат по имени пользователя

---

## 🧪 Задание 02

Определить самые популярные пиццерии.

Построить единый отчёт для:

* количества заказов
* количества посещений

Добавить вычисляемый столбец:

`action_type`

Возможные значения:

* order
* visit

Вывести топ-3 результата для каждого типа активности.

---

## 🧪 Задание 03

Построить объединённую статистику по пиццериям.

Для каждой пиццерии вычислить:

* количество заказов
* количество посещений
* общее количество действий

Получить:

* название пиццерии
* суммарное количество действий

Отсортировать результат:

1. по общему количеству по убыванию
2. по названию по возрастанию

---

## 🧪 Задание 04

Получить пользователей, посетивших пиццерии более трёх раз.

Вывести:

* имя пользователя
* количество посещений

Использование конструкции `WHERE` запрещено.

## 🧪 Задание 05

Получить список уникальных пользователей, совершивших хотя бы один заказ.

Вывести:

* имя пользователя

Отсортировать результат по имени.

Использование:

* GROUP BY
* UNION
* других операций над множествами

запрещено.

## 🧪 Задание 06

Построить статистику по каждой пиццерии.

Получить:

* количество заказов
* среднюю цену
* максимальную цену
* минимальную цену

Дополнительно:

* округлить среднюю цену до двух знаков после запятой
* отсортировать результат по названию пиццерии

## 🧪 Задание 07

Рассчитать общий средний рейтинг всех пиццерий.

Получить:

* global_rating

Дополнительно:

* округлить результат до четырёх знаков после запятой

## 🧪 Задание 08

Определить статистику заказов по адресам пользователей.

Получить:

* адрес
* название пиццерии
* количество заказов

Предполагается, что пользователь посещает только пиццерии своего города.

Отсортировать результат:

1. по адресу
2. по названию пиццерии

---

## 🧪 Задание 09

Построить агрегированный отчёт по каждому адресу.

Для каждого адреса вычислить:

* значение формулы

`MAX(age) - (MIN(age) / MAX(age))`

* средний возраст пользователей
* результат сравнения формулы со средним возрастом

Получить:

* address
* formula
* average
* comparison

Отсортировать результат по адресу.
