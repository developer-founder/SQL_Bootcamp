# 🧠 Data Warehouse

Проект посвящён изучению архитектуры хранилищ данных (DWH) и построению ETL-логики на основе SQL.

В рамках проекта рассматривается работа с разнородными источниками данных, обработка аномалий, работа с временными данными и построение аналитических запросов для подготовки витрин данных.

Основная цель — научиться мыслить в терминах DWH-архитектуры: источники → ODS → витрины данных, а также освоить принципы объединения данных из разных систем с разной степенью согласованности.

## 📖 Chapter I — Введение

Хранилище данных (DWH — Data Warehouse) — это система для сбора, хранения и анализа данных из разных источников с целью поддержки принятия решений.

В отличие от OLTP-систем, DWH ориентированы на аналитические запросы, агрегации и историчность данных.

Классические подходы к проектированию DWH включают:

- Inmon-архитектуру (корпоративное хранилище данных)
- Kimball-архитектуру (витрины данных и звёздная схема)
- Современные подходы: Data Lake и Lakehouse

DWH часто работает с несовершенными данными:
- пропуски (NULL)
- дубликаты
- отсутствие связей между источниками
- временные расхождения

## 🧪 Задание 00 — Classical DWH

Изучи источники данных (Green / Red / Blue Source Systems) и их интеграцию в DWH слой.

### 📌 Задача

Написать SQL-запрос, который возвращает общий объём транзакций пользователей, сгруппированный по:

- пользователю
- типу баланса

### 📊 Требуемые поля результата

- `name` — имя пользователя (если NULL → `'not defined'`)
- `lastname` — фамилия (если NULL → `'not defined'`)
- `type` — тип баланса
- `volume` — сумма всех операций
- `currency_name` — название валюты (если NULL → `'not defined'`)
- `last_rate_to_usd` — последний доступный курс валюты (если NULL → `1`)
- `total_volume_in_usd` — `volume * last_rate_to_usd`

### 📌 Особенности

- Источники данных могут быть несогласованы
- Возможны NULL значения
- Связи между таблицами не гарантированы
- Данные являются временными (OLTP → DWH трансформация)

### 📌 Сортировка результата

1. `name` — по убыванию  
2. `lastname` — по возрастанию  
3. `type` — по возрастанию
