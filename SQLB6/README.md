# 🧠 Traveling Salesman Problem

Проект посвящён изучению задачи коммивояжёра (Traveling Salesman Problem, TSP) и её решению средствами SQL в PostgreSQL.

В рамках выполнения заданий рассматриваются рекурсивные запросы, моделирование графов, поиск маршрутов, вычисление стоимости путей и анализ оптимальных решений.

Основная цель проекта — сформировать понимание работы с графовыми структурами в реляционных базах данных и освоить применение рекурсивных CTE для решения задач оптимизации.

## 🧩 Структура данных

Проект основан на графовой модели, включающей:

- **point1** — начальная вершина
- **point2** — конечная вершина
- **cost** — стоимость перехода между вершинами

Каждая запись описывает направленное ребро графа.

---

## 🧪 Задание 00

Создать таблицу маршрутов со структурой:

- point1
- point2
- cost

Заполнить таблицу данными графа.

Реализовать рекурсивный SQL-запрос, который:

- стартует из города `a`
- посещает все города ровно один раз
- возвращается в исходную точку
- вычисляет общую стоимость маршрута
- находит маршрут(ы) с минимальной стоимостью

Результат должен содержать:

- total_cost
- tour

Отсортировать результат по:

1. total_cost
2. tour
