# 🧠 PostgreSQL Indexes and Query Optimization

Проект посвящён изучению индексов PostgreSQL и практическому применению методов оптимизации SQL-запросов.

В рамках выполнения заданий рассматриваются различные типы индексов, анализ планов выполнения запросов, использование `EXPLAIN ANALYZE`, обеспечение уникальности данных и повышение производительности базы данных.

Основная цель проекта — сформировать понимание того, как PostgreSQL использует индексы, как они влияют на скорость выполнения запросов и каким образом можно оптимизировать работу системы хранения данных.

## ⚙️ Рекомендации к выполнению проекта

* Используй актуальную версию PostgreSQL
* Пиши SQL-запросы в удобной среде разработки (DataGrip, DBeaver, pgAdmin и др.)
* В репозитории должны оставаться только файлы, указанные в заданиях
* Настрой `.gitignore`, чтобы исключить лишние файлы
* Разверни предоставленную модель базы данных
* Используй `EXPLAIN ANALYZE` для анализа производительности запросов
* Внимательно соблюдай ограничения каждого задания
* Проверяй не только корректность результата, но и эффективность выполнения запросов

## 🧩 Структура базы данных

Проект основан на реляционной модели, включающей:

* **person** — пользователи системы
* **pizzeria** — список пиццерий
* **menu** — меню и цены
* **person_visits** — посещения пиццерий
* **person_order** — заказы пользователей

Связи между таблицами заданы через первичные и внешние ключи.

---

## 🧪 Задание 00

Создать B-Tree индексы для всех внешних ключей базы данных.

Требования:

* использовать простые индексы B-Tree
* придерживаться шаблона именования

`idx_<table_name>_<column_name>`

---

## 🧪 Задание 01

Подготовить SQL-запрос, выводящий:

* название пиццы
* название пиццерии

После этого:

* проверить использование созданных индексов
* предоставить доказательство работы индекса через `EXPLAIN ANALYZE`

---

## 🧪 Задание 02

Создать функциональный индекс:

`idx_person_name`

Требования:

* использовать столбец `name`
* сохранять значения в верхнем регистре (`UPPER(name)`)

Подготовить запрос и доказать использование индекса с помощью `EXPLAIN ANALYZE`.

---

## 🧪 Задание 03

Создать многоколоночный индекс:

`idx_person_order_multi`

Для запроса с фильтрацией по:

* person_id
* menu_id

Требования:

* добиться использования `Index Only Scan`
* предоставить подтверждение через `EXPLAIN ANALYZE`

---

## 🧪 Задание 04

Создать уникальный индекс:

`idx_menu_unique`

Для столбцов:

* pizzeria_id
* pizza_name

Подготовить запрос и доказать использование индекса через `EXPLAIN ANALYZE`.

---

## 🧪 Задание 05

Создать частично уникальный индекс:

`idx_person_order_order_date`

Требования:

* индексировать столбцы `person_id` и `menu_id`
* обеспечить уникальность только для даты `'2022-01-01'`

Проверить использование индекса через `EXPLAIN ANALYZE`.

---

## 🧪 Задание 06

Проанализировать предложенный SQL-запрос и подобрать индекс:

`idx_1`

Цель:

* уменьшить показатель Execution Time
* улучшить план выполнения запроса

Требования:

* сравнить результаты до оптимизации и после неё
* подтвердить улучшение с помощью `EXPLAIN ANALYZE`
